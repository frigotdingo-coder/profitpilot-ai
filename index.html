Рекомендации по формату

Для загрузки используйте CSV-файлы с заголовками колонок. Подходят данные по финансам, площадям, производству, ресурсам и поголовью. Данные загруженного файла отображаются только в текущем сеансе браузера.

Безопасность данных

Эта демонстрационная версия не отправляет файлы на сервер. Обработка CSV осуществляется локально в браузере. Не используйте демонстрационный интерфейс как защищённую корпоративную систему.
